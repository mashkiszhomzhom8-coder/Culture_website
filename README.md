# Cultural DIY — hero prototype

Мини-проект для VS Code. Сейчас реализован только первый экран в выбранной бордово-винтажной стилистике.

## Файлы

- `index.html` — структура hero-блока.
- `styles.css` — вся визуальная часть и анимации.
- `script.js` — заготовка под будущую интерактивность.
- `assets/reference-full.png` — полный визуальный референс.
- `assets/decor-left.png` и `assets/decor-right.png` — временные боковые коллажи.

## Как открыть

Проще всего: открыть папку в VS Code и запустить `index.html` через расширение **Live Server**.

Можно и просто дважды кликнуть `index.html`, но Live Server удобнее: после сохранения изменений страница автоматически обновляется.

## Куда смотреть при ручном редактировании

В `styles.css` в `:root` находятся основные цвета.

Главный заголовок регулируют `.hero__title`, `.hero__title > span` и `.hero__title em`.

Размер боковых объектов — `.hero__decor`.

Стартовая анимация — блок `/* ---------- АНИМАЦИИ ---------- */` и `@keyframes flyInLeft / flyInRight`.

## Следующий этап

Лучше заменить два цельных боковых коллажа отдельными прозрачными изображениями каждого предмета. Тогда рубашка, сумка, ваза, украшение и цветы смогут анимироваться отдельно, иметь разную скорость и появляться с небольшой задержкой друг за другом.
